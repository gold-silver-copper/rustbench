# Attribution

The tasks in this suite are generated by `tools/import_error_index.py` from
the Rust compiler's error index, the Markdown files in
`compiler/rustc_error_codes/src/error_codes/` of
[rust-lang/rust](https://github.com/rust-lang/rust) at commit
`6e4cba3380a6f9e1e4d7672e11e40372bf04e873`. Each task's `task.toml` names the
file it came from (`source`).

Each task's `workspace/` is an erroneous example from that file and its
`solution/` is the corrected example from the same file, with `//` comments
removed and, where the example has no `fn main`, wrapped in one the way
rustdoc does. The prompts are written for rustbench.
